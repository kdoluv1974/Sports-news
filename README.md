# صافرة — موقع تجميع أخبار الرياضة

## كيف يعمل
1. `fetch_news.py` يقرأ المصادر المذكورة في `sources.json` (خلاصات RSS)، يحذف المكرر، يصنّف الخبر حسب الرياضة، ويترجم العناوين غير العربية إلى العربية، ثم يكتب `docs/news.json`.
2. `docs/index.html` صفحة ثابتة تقرأ `news.json` وتعرض الأخبار مع التصفية والبحث.
3. GitHub Actions (`.github/workflows/update.yml`) يشغّل السكربت تلقائياً ويحفظ النتيجة.

## التجربة محلياً
```
pip install -r requirements.txt
python fetch_news.py
cd docs && python -m http.server 8000
```
ثم افتح http://localhost:8000

## النشر المجاني على GitHub Pages
1. ارفع المجلد إلى مستودع جديد على GitHub.
2. من Settings ← Pages اختر: Branch `main`، المجلد `/docs`.
3. من تبويب Actions شغّل "تحديث الأخبار" مرة يدوياً، وبعدها يعمل تلقائياً.

## تعديل المصادر
كل سطر في `sources.json` يحتوي: الاسم، رابط الخلاصة، لغة الخبر (`en` أو `ar`)، والرياضة (`general` ليصنّفها السكربت تلقائياً).
المصادر العربية مضبوطة عبر أخبار Google (`gnews: true`) لأن أغلب المواقع العربية لا توفر RSS ثابتاً.

## ملاحظات
- لم أستطع اختبار الروابط من بيئتي (لا يوجد اتصال بالإنترنت)، فشغّل السكربت مرة وراجع الرسائل: أي مصدر لا يعطي أخباراً يظهر فيه تحذير، فعدّل رابطه أو احذفه.
- الترجمة تستخدم مكتبة deep-translator المجانية. للجودة الأعلى يمكن استبدالها بواجهة Claude API داخل دالة `translate`.
- الموقع يعرض العنوان وملخصاً قصيراً مع رابط المصدر فقط، ولا ينسخ المقالات.
- `docs/news.json` الحالي بيانات تجريبية وسيُستبدل عند أول تشغيل.
